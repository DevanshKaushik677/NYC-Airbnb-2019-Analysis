# NYC Airbnb 2019 – Exploratory Data Analysis

## Project Overview

An exploratory data analysis of the NYC Airbnb 2019 dataset to understand pricing patterns, listing distributions, room types, neighbourhood differences, and host activity.

## Objectives

* Perform data cleaning and preprocessing.
* Handle missing values and inconsistencies.
* Conduct exploratory data analysis.
* Analyse pricing patterns across neighbourhoods and room types.
* Identify popular neighbourhoods and top hosts.
* Extract meaningful business insights.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Project Workflow

1. Data Loading and Inspection
2. Data Cleaning
3. Feature Engineering
4. Exploratory Data Analysis
5. Statistical Analysis
6. Data Visualization
7. Advanced Data Analysis
8. Key Findings and Conclusion

## Key Findings

* Manhattan and Brooklyn dominate Airbnb listing activity.
* Manhattan generally has the highest average listing prices.
* Entire homes/apartments are more expensive than private and shared rooms.
* Williamsburg has the highest number of listings among the neighbourhoods analysed.
* Some hosts manage hundreds of Airbnb listings.

## Dataset

NYC Airbnb Open Data (2019).

## Conclusion

This project provided practical experience in analysing real-world datasets using Python, performing data preprocessing, exploring statistical patterns, and extracting meaningful insights.
